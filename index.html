Pertanyaan Sering Diajukan

GAMEPLAY & SERVER
Apakah MineHera gratis dimainkan? +
Ya! Semua mode permainan di server MineHera 100% gratis dimainkan. Seluruh pendaftaran akun dan akses ke server tidak dipungut biaya apapun.
Mode permainan apa saja yang tersedia? +
MineHera mengusung fokus utama pada **Anarchy Server** tanpa aturan berbelit, tempat pemain bebas bertahan hidup, bertarung (PvP), menyerang basis musuh, atau membangun aliansi rahasia.
Berapa batas ukuran peta/world di server? +
World border kami diatur sangat luas untuk mendukung eksplorasi bebas, pembuatan basis tersembunyi berjarak jutaan blok, serta pertarungan jarak jauh tanpa rasa sesak.
Apakah pemain Bedrock (PE/Win10/Console) bisa bergabung? +
Ya, server kami mendukung cross-platform. Pemain Bedrock dapat masuk menggunakan IP `play.minehera.xyz` dan Port `19155`. Pastikan menggunakan titik (`.`) di awal username Anda.
TOKO, RANKS & PAYMENT
Apa itu Shards dan bagaimana cara menggunakannya? +
Shards adalah mata uang premium di MineHera. Shards dapat digunakan untuk membeli item kosmetik, kit khusus, serta upgrade langsung di dalam game melalui toko dalam game (`/shop`).
Berapa lama proses aktivasi setelah saya membayar? +
Sistem otomatis kami meneruskan bukti pembayaran ke Admin via Discord Webhook. Proses verifikasi dan pengiriman item biasanya memakan waktu 5–15 menit, atau maksimal 1x24 jam.
Bagaimana jika rank/shards saya tidak masuk? +
Jangan khawatir! Jika dalam 1x24 jam item belum diterima, silakan bergabung ke Server Discord Resmi MineHera dan buka **Support Ticket** dengan melampirkan foto bukti transaksi.
AKUN & KEAMANAN
Bagaimana cara mengamankan akun Minecraft saya? +
Saat pertama kali login di server, daftarkan akun Anda menggunakan perintah `/register [password] [password]`. Gunakan kombinasi kata sandi yang kuat dan jangan pernah membagikannya kepada siapa pun.
Bagaimana jika saya lupa kata sandi akun game saya? +
Gunakan saluran **Support Ticket** di Discord resmi kami untuk mengajukan permintaaan reset password akun. Tim Staff akan melakukan verifikasi kepemilikan akun sebelum meresetnya.
Apakah server menggunakan sistem Anti-Cheat? +
Ya! Kami menerapkan sistem perlindungan khusus untuk mencegah ekploitasi ilegal yang dapat merusak stabilitas server atau merugikan koneksi seluruh pemain.
